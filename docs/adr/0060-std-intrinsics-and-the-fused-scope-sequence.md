# Std intrinsics and the fused scope sequence

A std external whose native symbol is in a fixed table of `cheby_rt_` intrinsics gets a body generated by MIR lowering instead of a foreign call. Only std may bind `cheby_rt_` symbols (D-455), so users cannot reach an intrinsic.

M2 has one intrinsic, `scope_run`, private to `std::fiber`. It opens a scope, calls the body with an unwind edge, and closes the scope, with no Cheby call in between. On failure it returns a static `Err(Nil)`, and the cause stays in the fiber. All catch policy is in the runtime's scope close. `scope` and `timeout` are written in Cheby over it.

The fusion closes a window. If open, body and close were separate Cheby calls, the entry check of the close's wrapper could deliver a pending cancellation after the body returned. The unwinding would then leave the `scope` frame without closing it while its members still run, which breaks D-666. Opening and closing are runtime helpers without an entry check, so only the body's own entry check can deliver a cancellation, and it does so inside the scope.

## Considered options

- A kernel that calls the body through a trampoline: it puts a Rust frame under every scope body, often all of `main`, which pins the fiber to its thread or needs thread-local discipline in kernel code (D-675).
- Open, catch and close as three calls in Cheby: it leaves the window above.
- A general `catch` intrinsic: its pad would also catch a cancellation, which D-102 forbids, and no M2 code needs it.
- A new attribute that marks intrinsics: the reserved symbol already marks them, so the parser, resolver, interfaces and tree-sitter stay unchanged.

## Consequences

- Scope bodies run under JIT frames only.
- Catching allocates nothing, which matters after running out of memory.
- `scope_open` may raise only out of memory, before anything is open.
- The reason for a failure is read back through a `@std_context` kernel (D-692), and the `Panic` record is built in Cheby.
- Each intrinsic declares an `@external(js, …)` binding like any kernel.
- Any later catching intrinsic must let a cancellation pass and catch only a panic, as the scope close does.
