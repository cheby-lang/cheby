# E0020: missing type annotation in a signature

Top-level functions and constants need full signatures (D-011). Every parameter of a top-level function needs a type, and so does every constant. Types are inferred only inside bodies, which keeps error messages local and lets each declaration be checked on its own.

The return type of a function may be left out only when it is `Nil` (D-083).

Example:

```cheby
fn double(x) -> Int {
  x * 2
}

const limit = 10
```

Write the types:

```cheby
fn double(x: Int) -> Int {
  x * 2
}

const limit: Int = 10
```

Closures and local functions may leave their parameter types out (§5.7, §5.8).
