# E0024: positional tuple access

Tuples and positional variant fields are read with patterns, not with `.0`, `.1` and so on (D-241). A pattern names each part where it is used, which keeps the meaning visible.

Example:

```cheby
fn first(pair: (Int, String)) -> Int {
  pair.0
}
```

Take the tuple apart with a pattern:

```cheby
fn first(pair: (Int, String)) -> Int {
  let (number, _) = pair
  number
}
```

Closures can take the pattern as their parameter: `fn((number, _)) { number }` (D-242).
