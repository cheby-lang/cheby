# E0030: tuple with fewer than two elements

A tuple has two or more elements (D-076). `(x)` is just `x` in parentheses, and there are no empty or one-element tuples: `()`, `(x,)` and the types `()` and `(T,)` are errors. Types have no parentheses for grouping, so the type `(T)` is a one-element tuple and an error too (D-436). The value with no information is `Nil`, of type `Nil` (D-065).

Example:

```cheby
fn wrap(x: Int) -> (Int,) {
  (x,)
}
```

Use the value itself, or a tuple with at least two elements:

```cheby
fn wrap(x: Int) -> Int {
  x
}
```
