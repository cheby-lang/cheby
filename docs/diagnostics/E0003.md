# E0003: character that cannot start a token

The character is not part of any token of the language (§2.6). Outside string literals and comments, Cheby source uses only ASCII letters, digits, whitespace and the operators and punctuation of §2.6. Characters such as `;`, `$`, `?`, `#` and `~`, and any non-ASCII character, are errors there.

The most common case is a semicolon. Cheby has no semicolons: newlines separate statements (§2.8).

Example:

```cheby
fn total(price: Int, count: Int) -> Int {
  price * count;
}
```

Remove the semicolon:

```cheby
fn total(price: Int, count: Int) -> Int {
  price * count
}
```

Non-ASCII text belongs in string literals and comments, where any character is allowed.
