# E0064: `dyn I` where a function of `I` uses `Self` other than as its first parameter

A `dyn I` value holds some value whose type satisfies `I`, and calls go through the functions packaged with it (§8.6). That works only when `Self` is the first parameter of each function of `I`, including embedded ones, and appears nowhere else (D-117). A `dyn` value cannot supply a second `Self` argument of the same hidden type, and the caller would not know the type of a `Self` result. The message names the function that breaks the rule.

Example:

```cheby
import std::list

interface Shape {
  fn area(Self) -> Float
  fn scale(Self, Float) -> Self
}

fn total_area(shapes: List<dyn Shape>) -> Float {
  list::fold(shapes, 0.0, fn(sum, shape) { sum + Shape::area(shape) })
}
```

Put the functions that `dyn` needs in an interface of their own:

```cheby
import std::list

interface Area {
  fn area(Self) -> Float
}

fn total_area(shapes: List<dyn Area>) -> Float {
  list::fold(shapes, 0.0, fn(sum, shape) { sum + Area::area(shape) })
}
```
