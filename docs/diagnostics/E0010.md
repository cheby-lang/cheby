# E0010: string literal without its closing quote

A string literal ends at the next `"` that is not escaped, and a raw string at the next `"` followed by as many `#` as after its `r` (§2.5.3, D-130). This one reaches the end of the file first.

Strings may span lines, so a missing quote takes in the rest of the file. The error points to where the string starts.

Example:

```cheby
const greeting: String = "hello
```

Close the string:

```cheby
const greeting: String = "hello"
```

To put a `"` inside a string, write `\"`, or use a raw string with hashes: `r#"a "quoted" word"#`.
