# E0071: numeric literal that does not fit its type

A numeric literal takes its type from its context and must fit in it (D-084, §3.3.4). `256` is an error where a `U8` is expected, and `-1` is an error where any unsigned type is expected (D-470). On the JS target, an `Int` literal must also be inside the JS safe-integer range, from -(2^53 - 1) to 2^53 - 1 (D-037).

Example:

```cheby
fn max_byte() -> U8 {
  256
}
```

Write a value the type can hold, or use a wider type:

```cheby
fn max_byte() -> U8 {
  255
}
```
