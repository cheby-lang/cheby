# E0037: module file or directory name that is not a valid name

A module's path comes from its file's path under `src/` (§7.2), so the names of `.cheby` files and of directories under `src/` must be `snake_case` identifiers that are not keywords or reserved words (§2.3, §2.4, D-059). Hidden files and directories are ignored, and so are files that are not `.cheby` files, such as JS helpers (D-208).

For example, `src/HttpClient.cheby` and `src/web-server/` are errors. Rename them to `src/http_client.cheby` and `src/web_server/`, and import them as `my_app::http_client`.
