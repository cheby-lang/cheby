# E0001: source file is not valid UTF-8

A Cheby source file must be UTF-8 text (§2.1). The compiler reports this error at the first byte that is not part of a valid UTF-8 sequence, and does not parse the file.

The usual cause is a file saved in another encoding, such as Latin-1 or UTF-16. Save the file as UTF-8. A byte-order mark at the start of the file is allowed and ignored.

The snippet shows the line with the bad byte, with invalid bytes replaced by `U+FFFD`.
