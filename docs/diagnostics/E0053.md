# E0053: native symbol of an `@external` that is not defined

A function bound with `@external(native, "symbol")` calls the C function of that name (§12.5, D-030, D-455). When the program is built or run, the symbol must be defined by the Cheby runtime, by a library the program is linked with, or by the process itself. If nothing defines it, the program cannot run, and the error points at the `@external` that names the symbol.

`cheby check` does not report this error, because which symbols exist is known only when the program is linked or loaded. `cheby run` reports it before the program starts, even when the function is never called.

Example, where no library defines `clock_now_ms`:

```cheby
@external(native, "clock_now_ms")
fn now() -> Int

fn main() {
  Nil
}
```

Check the spelling of the symbol, or link the library that defines it. A symbol that exists only on some systems needs a function body or an `@external` for each target instead.
