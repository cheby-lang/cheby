# E0073: test body whose type is neither `Nil` nor `Result<Nil, E>`

A `test` body has type `Nil` or `Result<Nil, E>` for some `E` (§4.7, D-140). A test passes if its body completes without panicking and, for a `Result` body, returns `Ok(Nil)`. Any other type would be silently ignored, which usually means an `assert` is missing, and for a `Bool` body the help suggests `assert`. A body of type `Never`, such as one that ends in `panic`, counts as `Nil`, and a body whose type nothing determines is `Nil` (D-493).

Example:

```cheby
fn double(n: Int) -> Int {
  n * 2
}

test "double doubles" {
  double(2) == 4
}
```

Assert the condition:

```cheby
fn double(n: Int) -> Int {
  n * 2
}

test "double doubles" {
  assert double(2) == 4
}
```
