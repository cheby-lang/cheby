# W0008: `let assert` with an irrefutable pattern

`let assert` is for patterns that may fail to match, and it panics when they do (§11, D-068). When the pattern matches every value of its type, the `assert` can never fail and only misleads the reader (D-159). Use a plain `let`.

Example:

```cheby
fn sum(pair: (Int, Int)) -> Int {
  let assert (a, b) = pair
  a + b
}
```

Use `let`:

```cheby
fn sum(pair: (Int, Int)) -> Int {
  let (a, b) = pair
  a + b
}
```
