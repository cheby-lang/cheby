# W0008: `let assert` with an irrefutable pattern

`let assert` is for patterns that may fail to match, and it panics when they do (§11.4, D-068). When the pattern matches every value of its type, the `assert` can never fail and only misleads the reader (D-159). Use a plain `let`. Irrefutability follows the syntactic list of §6.1, so `let assert True | False = b` does not warn (D-509).

Example:

```cheby
fn sum(pair: (Int, Int)) -> Int {
  let assert (a, b) = pair
  a + b
}
```

Use `let`:

```cheby
fn sum(pair: (Int, Int)) -> Int {
  let (a, b) = pair
  a + b
}
```
