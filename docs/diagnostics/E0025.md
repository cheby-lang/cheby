# E0025: `_` that is not a whole call argument

In an expression, `_` is allowed only as a whole argument of a call, where it makes the call a function capture: `int::add(1, _)` means `fn(x) { int::add(1, x) }` (§5.6, D-202). Anywhere else, such as inside an operator expression or as a value of its own, it is an error.

Example:

```cheby
import std::list

fn increment_all(numbers: List<Int>) -> List<Int> {
  list::map(numbers, _ + 1)
}
```

Write a closure:

```cheby
import std::list

fn increment_all(numbers: List<Int>) -> List<Int> {
  list::map(numbers, fn(n) { n + 1 })
}
```
