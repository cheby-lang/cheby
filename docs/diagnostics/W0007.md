# W0007: local declaration or import that hides a prelude name

The prelude makes types such as `Option` and `Result` and constructors such as `Some` and `Ok` available in every module. A declaration or an explicit item import with the same name hides the prelude item in that module. This is allowed, so that adding a name to the prelude never breaks existing code, but it is a warning, because readers expect the prelude meaning (D-146).

Types and constructors live in separate namespaces (D-111), and only a name in the same namespace hides anything: a type hides a prelude type, and a constructor hides a prelude constructor. A constructor named `String`, as in `type Value { String(String) }`, hides nothing and is not reported (D-212). Importing a prelude type through its home module, as in `import std::option::{Option}`, names the same item and is not reported either (D-447).

Example:

```cheby
type Result {
  Pass,
  Fail(String),
}
```

Rename the item if the hiding is not intended:

```cheby
type Outcome {
  Pass,
  Fail(String),
}
```
