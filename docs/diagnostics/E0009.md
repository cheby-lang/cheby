# E0009: numeric literal with a suffix

Numeric literals have no type suffixes (D-084). A literal takes its type from where it is used: an annotation, a parameter type or a signature (§3.3.4). Letters right after the digits are an error.

Example:

```cheby
const limit: U8 = 200u8
const ratio: F32 = 0.5f
```

Remove the suffix. The declared type already gives the literal its type:

```cheby
const limit: U8 = 200
const ratio: F32 = 0.5
```
