# E0023: bound or type argument where none is allowed

Bounds such as `T: Show` belong on functions and interfaces, not on the type parameters of a type declaration or alias (§4.3). A bound or a `dyn` type names an interface, written without type arguments. An interface function such as `Show::show` takes no type arguments either, because interface functions are not generic (D-165).

Example:

```cheby
type Labelled<T: Show> {
  value: T,
}
```

Declare the type without the bound, and put the bound on the functions that need it:

```cheby
type Labelled<T> {
  value: T,
}

fn describe<T: Show>(item: Labelled<T>) -> String {
  let value = item.value
  "labelled {value}"
}
```
