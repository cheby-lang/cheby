# E0035: subjectless `case` without a final `_` arm

A `case` without a subject tries its conditions in order, and its last arm must be `_`, which covers every remaining case (D-109). The compiler does not reason about which conditions can be true together, so the final `_` is what makes the `case` complete. A `_` arm before the last is the same error, because every other arm needs a `Bool` condition and `_` is not one (D-439).

Example:

```cheby
fn sign(n: Int) -> String {
  case {
    n < 0 => "negative"
    n > 0 => "positive"
    n == 0 => "zero"
  }
}
```

End with `_`:

```cheby
fn sign(n: Int) -> String {
  case {
    n < 0 => "negative"
    n > 0 => "positive"
    _ => "zero"
  }
}
```
