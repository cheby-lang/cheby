# E0014: line break where the line does not continue

Newlines end statements, `case` arms and items (§2.8). A line continues onto the next one only when (D-231):

- it is inside an unclosed `(`, `[` or the `<` of type arguments or type parameters,
- it ends with a binary operator, `,`, `=`, `=>`, `->` or `<-`,
- or the next line starts with `|>`, `&&` or `||`.

Anywhere else, a line break ends what came before it, and here that left something incomplete.

Example:

```cheby
fn total(price: Int, tax: Int) -> Int {
  let sum
    = price + tax
  sum
}
```

Keep the `=` on the first line, where it continues the statement:

```cheby
fn total(price: Int, tax: Int) -> Int {
  let sum = price + tax
  sum
}
```

A leading `-` never continues a line, so it always starts a new expression. Break long expressions after an operator, or before `|>`, `&&` and `||`.
