# E0029: chained comparison

Comparison operators do not chain (D-108). `a < b < c` would compare the `Bool` result of `a < b` with `c`, which is almost never what was meant, so it is an error.

Example:

```cheby
fn in_range(low: Int, x: Int, high: Int) -> Bool {
  low <= x < high
}
```

Combine the comparisons with `&&`:

```cheby
fn in_range(low: Int, x: Int, high: Int) -> Bool {
  low <= x && x < high
}
```
