# E0059: record construction or update with missing, repeated or unknown fields, or a named-field constructor called positionally or used as a value

A named-field constructor is used with braces, and the braces must initialize every field of the variant exactly once, in any order (§5.11.1). A field that the variant does not have, a field written twice and a field left out are all this error. A record update `T { ..base, … }` lists at least one field, each at most once (§5.11.2, D-156).

A named-field constructor is never called positionally, as in `Point(1, 2)`, and is never used as a function value (D-138). Field order is therefore never significant, and reordering the fields of a type never breaks the code that builds it.

Example:

```cheby
type Point {
  x: Int,
  y: Int,
}

fn origin() -> Point {
  Point { x: 0 }
}
```

Initialize every field:

```cheby
type Point {
  x: Int,
  y: Int,
}

fn origin() -> Point {
  Point { x: 0, y: 0 }
}
```
