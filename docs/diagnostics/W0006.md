# W0006: `Result` discarded in statement position

A statement whose value is a `Result` throws the result away, and with it any error (§13.8, D-153). Silently dropped errors are a common bug, so this is a warning. Write `let _ = …` to discard a result on purpose. Values of other types may be discarded silently.

Example:

```cheby
import std::io

fn save(name: String) -> Result<Nil, String> {
  case name {
    "" => Err("empty name")
    _ => Ok(Nil)
  }
}

fn main() {
  save("report")
  io::println("saved")
}
```

Handle the error, or discard the result explicitly:

```cheby
import std::io

fn save(name: String) -> Result<Nil, String> {
  case name {
    "" => Err("empty name")
    _ => Ok(Nil)
  }
}

fn main() {
  case save("report") {
    Ok(Nil) => io::println("saved")
    Err(message) => io::eprintln(message)
  }
}
```
