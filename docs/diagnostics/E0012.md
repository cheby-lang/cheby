# E0012: invalid string interpolation

Inside a string literal, `{` starts an interpolation that ends at the next `}`. Between the braces only a name is allowed, optionally followed by field names and then `:?`, with no spaces (§2.5.4, D-115):

```cheby
"hello {name}"
"at {point.x}, {point.y}"
"debug: {state:?}"
```

Anything else, such as an expression, a tuple position or an empty `{}`, is an error, and so is a `{` without its `}`. An interpolation must also fit on one line: a line break ends it, so a `}` on the next line does not close it.

Example:

```cheby
fn label(count: Int) -> String {
  "next: {count + 1}"
}
```

Bind the value to a name first:

```cheby
fn label(count: Int) -> String {
  let next = count + 1
  "next: {next}"
}
```

To write a literal brace, escape it as `\{`. A closing `}` needs no escape.
