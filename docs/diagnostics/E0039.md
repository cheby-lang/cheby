# E0039: import of a module or package that does not exist

An import path starts with a package, then names a module inside it (§7.5, D-111). The first segment is the current package's own name from `cheby.toml`, a dependency key from the manifest, or `std` (D-238). This error means that the package or the module does not exist.

The root module, `src/main.cheby`, is imported by the package name alone, never as `my_app::main` (D-142).

Example, in package `my_app` with the files `src/main.cheby` and `src/web.cheby`:

```cheby
import my_app::main
import my_app::webb
import std::nope
```

Fix the paths:

```cheby
import my_app
import my_app::web
import std::io
```
