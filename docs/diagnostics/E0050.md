# E0050: `main` without the signature of an entry point

Any module's top-level `main` can be run by its module path (D-137), so every top-level function named `main` must be an entry point: it takes no parameters and returns `Nil` or `Result<Nil, E>` for some `E` (§4.2.1, D-073, D-448). Its visibility does not matter (D-163).

Example:

```cheby
fn main(name: String) -> Int {
  0
}
```

Take no parameters and return `Nil` or a `Result`:

```cheby
import std::io

fn main() {
  io::println("hello")
}
```
