# E0011: invalid escape sequence

A string literal allows exactly these escapes (§2.5.3, D-114):

| Escape  | Meaning                                                 |
| ------- | ------------------------------------------------------- |
| `\n`    | line feed                                               |
| `\t`    | tab                                                     |
| `\r`    | carriage return                                         |
| `\\`    | backslash                                               |
| `\"`    | double quote                                            |
| `\{`    | `{`, which would otherwise start an interpolation       |
| `\u{…}` | a Unicode scalar value, 1 to 6 hex digits, no surrogate |

Any other `\` sequence is an error.

Example:

```cheby
const digits: String = "\d+"
```

For text with many backslashes, such as a regular expression, use a raw string, which has no escapes. Otherwise escape the backslash:

```cheby
const digits: String = r"\d+"
const same_digits: String = "\\d+"
```
