# W0003: unused import

An import that nothing in the module uses is a warning (§13.8, D-080). A module import counts as used when a path goes through it, and an item import when the item is named. In a module of the local package, satisfaction never needs an import: a built-in type gets its functions from its home module without one (D-447), so an import that only brings in such a module, and that nothing names, is unused too. Implicit uses, such as the `show` that `"{n}"` calls or the function behind an operator, never use an import, so an `import std::int` that serves only `"{n}"` is unused (§7.5.3, D-515). A module of the standard library is the exception: it depends only on what it imports, so there an import of a built-in type's home module is used when satisfaction takes a function from it, and its `import std::int` that serves `"{n}"` is not reported (§7.5.3, D-489, D-762). The warning is reported only when every body of the module type-checked (D-516).

Example:

```cheby
import std::io
import std::list

fn main() {
  io::println("hello")
}
```

Remove the import:

```cheby
import std::io

fn main() {
  io::println("hello")
}
```
