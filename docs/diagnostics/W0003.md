# W0003: unused import

An import that nothing in the module uses is a warning (§13.8, D-080). A module import counts as used when a path goes through it, and an item import when the item is named. An import that a type needs only so that it satisfies an interface, such as the home module of a built-in type, also counts as used.

Example:

```cheby
import std::io
import std::list

fn main() {
  io::println("hello")
}
```

Remove the import:

```cheby
import std::io

fn main() {
  io::println("hello")
}
```
