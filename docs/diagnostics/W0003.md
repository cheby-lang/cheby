# W0003: unused import

An import that nothing in the module uses is a warning (§13.8, D-080). A module import counts as used when a path goes through it, and an item import when the item is named. Satisfaction never needs an import: a built-in type gets its functions from its home module without one (D-447), so an import that only brings in such a module, and that nothing names, is unused too.

Example:

```cheby
import std::io
import std::list

fn main() {
  io::println("hello")
}
```

Remove the import:

```cheby
import std::io

fn main() {
  io::println("hello")
}
```
