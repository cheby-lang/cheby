# W0011: `==` or `!=` on a type statically known to contain a function or handle

`==` and `!=` compare values structurally, and they panic when they reach a function value or a handle, such as a channel end, a fiber or a value of an external type (§3.13, D-070, D-233). When the operands' type is known to contain such a type, the comparison will panic whenever it reaches it, so the compiler warns.

Example:

```cheby
type Handler {
  name: String,
  run: fn(Int) -> Int,
}

fn same(a: Handler, b: Handler) -> Bool {
  a == b
}
```

Compare the parts that can be compared:

```cheby
type Handler {
  name: String,
  run: fn(Int) -> Int,
}

fn same(a: Handler, b: Handler) -> Bool {
  a.name == b.name
}
```
