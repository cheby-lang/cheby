# W0011: `==` or `!=` on a type statically known to contain a function or handle

`==` and `!=` compare values structurally, and they panic when they reach a function value or a handle, such as a channel end, a fiber or a value of an external type (§3.13, D-070, D-233). When the operands' type is known to contain such a type, the comparison will panic whenever it reaches it, so the compiler warns. It looks through tuples, built-in collections and the fields of every constructor of a named type, and stops at type parameters, at `dyn` values and at standard-library types that compare through their own functions (D-518). The handles of the standard library, `channel::Sender`, `channel::Receiver`, `fiber::Scope`, `fiber::Fiber` and `selector::Selector`, are external types of their modules, so a type that contains one is warned about too (D-647).

Example:

```cheby
type Handler {
  name: String,
  run: fn(Int) -> Int,
}

fn same(a: Handler, b: Handler) -> Bool {
  a == b
}
```

Compare the parts that can be compared:

```cheby
type Handler {
  name: String,
  run: fn(Int) -> Int,
}

fn same(a: Handler, b: Handler) -> Bool {
  a.name == b.name
}
```
