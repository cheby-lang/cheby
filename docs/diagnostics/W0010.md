# W0010: `case` arm that can never match

Arms of a `case` are tried in order, and an arm is unreachable when the arms before it already match every value it could match (§6.9, D-022). It is usually a mistake in the order of the arms, or an arm left over after a change. An arm with a guard does not hide later arms, since its guard may be false (§5.9.3). When the patterns are too complex to check within the budget, the arms not yet checked count as reachable and get no warning (D-508).

Example:

```cheby
fn describe(n: Int) -> String {
  case n {
    _ => "some"
    0 => "none"
  }
}
```

Put the more specific arm first:

```cheby
fn describe(n: Int) -> String {
  case n {
    0 => "none"
    _ => "some"
  }
}
```
