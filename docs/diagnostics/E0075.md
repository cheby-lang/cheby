# E0075: constant whose initializer panicked during evaluation

A constant's initializer runs at compile time (§4.5, D-090). If it panics, for example by dividing by zero, failing an `assert` or calling `panic`, the constant has no value and the program cannot be built. The error points at the constant's name, and a note gives the panic's message and the location where it started (D-533). Constant evaluation never prints the panic report itself (D-449). `cheby check` evaluates every constant of the package, so it reports this error too (D-459, D-534).

When the initializer reads another constant whose own initializer panics, the error is reported once, at the constant whose initializer panicked. The constants that read it are not reported again, so with `next = base + 1` only `base` gets the error (D-592).

Example:

```cheby
const ratio: Int = 100 / parts()

fn parts() -> Int {
  0
}
```

Make sure the initializer cannot panic for the values it computes with:

```cheby
const ratio: Int = 100 / parts()

fn parts() -> Int {
  4
}
```
