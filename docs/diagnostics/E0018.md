# E0018: module header out of order

A file has one fixed order: `//!` module docs, then inner attributes such as `@!target(js)`, then imports, then items (D-141, D-143, D-201). One place to look for imports keeps files easy to read and to format.

Example:

```cheby
fn helper() -> Int {
  1
}

import std::int
```

Move the import before the first item:

```cheby
import std::int

fn helper() -> Int {
  1
}
```
