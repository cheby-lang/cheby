# E0080: mention of `context::key` or `context::key_without_default` that is not the call that is a constant's whole initializer

A context key is a constant, and the constant is what identifies it: a key is its constant's path and the type of its values ([§10.11](../spec/10-concurrency.md#1011-context-values), D-1045, D-1564). So `context::key` and `context::key_without_default` may be mentioned only as the function called in the call that is the whole initializer of a `const`. Every other mention in an expression is this error, reported at the mention (D-1565):

- a call anywhere else, in a function body or nested inside a constant's initializer, as in `const k: Option<context::Key<Int>> = Some(context::key(0))`;
- a block around the call, as in `const k: context::Key<Int> = { context::key(0) }`, because the block's value only ends in the call (D-1581);
- a function value, as in `let make = context::key`, and a pipe stage, as in `0 |> context::key`.

`context::key(_)` is E0027 instead, as every call whose only argument is `_` is (D-245). Reaching `key` through an interface, by an interface call, a bound or a `dyn` value, is not this error but E0063: the key functions never count toward satisfying an interface, so the type does not satisfy it (§8.2, D-1593).

The rule comes from the attribute `@std_initializer` that the standard library writes on both functions: it marks a function that may only initialize a constant and names the function the compiler calls in its place, with the constant's path and the text of its value type (§4.8, D-1599). A key made anywhere else would have no constant, so it would have no path that names it. Parentheses around the call change nothing, a call with type arguments, `context::key::<Int>(0)`, is the call too, and an import such as `import std::context::{key}` is not a mention, so `key(0)` may then be the initializer (D-1581).

Example:

```cheby
import std::context

fn greeting() -> context::Key<String> {
  context::key("hello")
}
```

Make the call the whole initializer of a constant, and use the constant:

```cheby
import std::context

const greeting: context::Key<String> = context::key("hello")
```
