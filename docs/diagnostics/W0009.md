# W0009: `todo` in compiled code

`todo` marks code that is not written yet (§5.14, D-068). It has type `Never`, so it fits anywhere, and it panics when it is reached. The compiler warns about every `todo` it compiles, whether or not it can be reached, so that none is forgotten before a release.

Example:

```cheby
fn circle_area(radius: Float) -> Float {
  todo as "area of a circle"
}
```

Write the code:

```cheby
fn circle_area(radius: Float) -> Float {
  3.141592653589793 * radius * radius
}
```
