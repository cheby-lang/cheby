# E0063: type that does not satisfy a required interface

A type satisfies an interface when the module that declares the type has a function for each function of the interface, with the matching signature, at least as visible as the type (§8.2, D-020, D-061, D-164). Built-in types are treated as declared in their standard-library module, such as `Int` in `std::int` (D-105, D-447). This error is reported where satisfaction is required and missing: a bounded type parameter such as `T: Show` (§8.4), `{x}` interpolation, which needs `Show` (D-086), an operator such as `+` or `<` (§8.7), an interface call such as `Compare::compare(a, b)`, and a conversion to `dyn I` (§8.6).

The notes say which function the type's module is missing, or which function is too little visible to count. A `pub` type whose `show` is only package-visible does not satisfy `Show`, and the help suggests making it `pub` (D-164). For interpolation, the help also suggests `{x:?}`, which uses built-in debug printing and needs no interface.

Example:

```cheby
import std::io

type Point {
  x: Int,
  y: Int,
}

fn main() {
  let origin = Point { x: 0, y: 0 }
  io::println("{origin}")
}
```

Give the type's module a `show` function, or debug-print the value with `{origin:?}`:

```cheby
import std::io

type Point {
  x: Int,
  y: Int,
}

fn show(p: Point) -> String {
  "({p.x}, {p.y})"
}

fn main() {
  let origin = Point { x: 0, y: 0 }
  io::println("{origin}")
}
```
