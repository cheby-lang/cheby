# E0049: call of a value that is not a function

Only functions can be called (§5.6). The expression before the parentheses has a type that is not a function type, such as `String` or `Int`.

Example:

```cheby
fn main() {
  let greeting = "hello"
  let x = greeting("world")
}
```

Call a function, and pass the value as its argument:

```cheby
import std::string

fn main() {
  let greeting = "hello"
  let x = string::join([greeting, "world"], " ")
}
```
