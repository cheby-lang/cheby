# E0041: name declared or imported twice in one module

Each name may be declared once in each namespace of a module (§7.7). Types, aliases and interfaces share the type namespace, and functions, constants, constructors and imported module names share the value namespace. Two items with the same name in one namespace, or an import whose name is already taken by an item or another import, are an error (D-062). Two tests with the same name in one module are reported with this code too (§4.7, D-462).

Example:

```cheby
import my_app::list
import std::list

fn total(xs: List<Int>) -> Int {
  list::fold(xs, 0, fn(sum, x) { sum + x })
}

fn total(xs: List<Int>) -> Int {
  list::length(xs)
}
```

Rename one of the items, and give one of the imports an alias with `as`:

```cheby
import my_app::list as my_list
import std::list

fn total(xs: List<Int>) -> Int {
  list::fold(xs, 0, fn(sum, x) { sum + x })
}

fn count(xs: List<Int>) -> Int {
  list::length(xs)
}
```
