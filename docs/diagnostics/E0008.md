# E0008: malformed numeric literal

A numeric literal does not have one of the forms of §2.5.1 and §2.5.2:

- a decimal integer has no leading zero unless it is `0`, so `0755` is an error, because C reads it as octal,
- a prefix `0x`, `0o` or `0b` must be followed by a digit of that base, not by `_` and not by nothing (D-433),
- every digit must belong to the base: `0b102` and `0o78` are errors,
- a float has digits on both sides of the `.`, and an exponent has at least one digit.

`_` may separate digits anywhere after the first digit and carries no meaning.

Example:

```cheby
const permissions: Int = 0755
const mask: Int = 0x_ff
```

Write the octal value with its prefix and start the hex digits right after `0x`:

```cheby
const permissions: Int = 0o755
const mask: Int = 0xff
```
