# E0070: type alias that refers to itself or leaves a type parameter unused

A type alias is another name for an existing type, and it is replaced by its definition wherever it is used (§4.4, D-081). An alias that refers to itself, directly or through other aliases, would never finish expanding, so it is an error. A recursive type needs a type declaration instead. Every type parameter of an alias must be used in its definition, since an unused parameter would make different-looking types equal. Uses of an alias with an error report nothing more (D-490).

Example:

```cheby
type Pair<A, B> = (A, A)
```

Use every type parameter, or remove the ones you do not need:

```cheby
type Pair<A, B> = (A, B)
```
