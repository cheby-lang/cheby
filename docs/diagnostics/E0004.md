# E0004: block comment

Cheby has no block comments (D-078). A comment starts with `//` and runs to the end of the line. `///` documents the item that follows, and `//!` documents the module (§2.2).

The error covers the whole `/* … */`, so the rest of the file is still checked.

Example:

```cheby
/* Adds two numbers. */
fn add(a: Int, b: Int) -> Int {
  a + b
}
```

Use a line comment, here a doc comment because it describes the function:

```cheby
/// Adds two numbers.
fn add(a: Int, b: Int) -> Int {
  a + b
}
```
