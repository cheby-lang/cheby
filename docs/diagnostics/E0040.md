# E0040: modules that import each other in a cycle

Modules must not import each other cyclically, directly or through other modules (§7.5.3, D-145). The error lists the modules on the cycle. A cycle would make the evaluation order of constants, REPL reloading and incremental builds depend on more than the import graph.

Example, where `src/a.cheby` imports `my_app::b` and `src/b.cheby` imports `my_app::a`:

```cheby
//! The `a` module.

import my_app::b

pub fn twice(n: Int) -> Int {
  b::double(n)
}
```

```cheby
//! The `b` module.

import my_app::a

pub fn double(n: Int) -> Int {
  n * 2
}
```

Break the cycle: here `b` does not use `a`, so remove its import. When both modules need each other's items, move the shared items to a third module that both import.
