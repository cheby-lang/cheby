# E0034: interpolation in a string pattern

A string literal pattern matches a fixed string, so it cannot contain an interpolation (§6.3). Raw strings are allowed in patterns.

Example:

```cheby
fn is_greeting(name: String, text: String) -> Bool {
  case text {
    "hello {name}" => True
    _ => False
  }
}
```

Compare with `==`:

```cheby
fn is_greeting(name: String, text: String) -> Bool {
  text == "hello {name}"
}
```
