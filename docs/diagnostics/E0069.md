# E0069: constants that refer to each other in a cycle

Constants may refer to other constants, but not cyclically, since each one is evaluated from the others at compile time (§4.5). The front end reports a cycle of constants that name each other directly in their initializers. The message lists the constants in the cycle.

Example:

```cheby
const width: Int = height * 2
const height: Int = width / 2
```

Give one of the constants a value that does not depend on the other:

```cheby
const width: Int = height * 2
const height: Int = 10
```
