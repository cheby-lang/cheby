# E0072: non-overloadable operator applied to a type it is not defined for

Some operators work only on built-in types and cannot be overloaded (D-118). `%` is defined on the numeric types (§5.4.2). The bitwise operators `&`, `|`, `^`, `<<` and `>>` are defined on the integer types (§5.4.6). Using one of them on another type is this error. Like the other operators, they are resolved at the end of the function body, once the operand type is known (D-234).

Operators that a type can provide through an interface, such as `+` or `<`, report a missing interface instead (E0063). `&&`, `||` and `!` take `Bool` operands (§5.4.5), so another operand is a type mismatch (E0047, D-495). An operand of type `Never` gets this error for `%`, the bitwise operators and the shifts, like any other type that is not numeric (D-492).

Example:

```cheby
fn both(a: Bool, b: Bool) -> Bool {
  a & b
}
```

`&` is bitwise and works on integers. Use the logical operator:

```cheby
fn both(a: Bool, b: Bool) -> Bool {
  a && b
}
```
