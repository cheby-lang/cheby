# E0031: malformed record update

A record update is written `T { ..base, field: value, … }` (§5.11.2, D-035, D-156). The spread `..base` comes first and only once, and at least one field follows it. `T` is the type's name, optionally qualified with its module.

Example:

```cheby
type Point {
  x: Float,
  y: Float,
}

fn move_right(p: Point) -> Point {
  Point { x: 1.0, ..p }
}
```

Put the spread first:

```cheby
type Point {
  x: Float,
  y: Float,
}

fn move_right(p: Point) -> Point {
  Point { ..p, x: p.x + 1.0 }
}
```

To copy a value unchanged, use it as it is.
