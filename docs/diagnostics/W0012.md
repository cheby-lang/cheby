# W0012: use of a `@deprecated` item

`@deprecated("message")` on a `pub` item makes every use of the item from another module a warning that includes the message (§4.8, D-200). It lets a library discourage an item without removing it, under the compatibility promise (D-075). Uses inside the item's own module are not reported. Every written name that refers to the item warns, including a constructor of a deprecated type and a function of a deprecated interface. An item import does not warn, but each use of the name it binds does, and implicit uses, such as a deprecated `show` that an interpolation calls, do not warn (D-517).

Example, where `src/text.cheby` in package `my_app` marks `yell` as deprecated in favor of `shout`:

```cheby
import std::io
import my_app::text

fn main() {
  io::println(text::yell("hello"))
}
```

Follow the message and use the replacement:

```cheby
import std::io
import my_app::text

fn main() {
  io::println(text::shout("hello"))
}
```
