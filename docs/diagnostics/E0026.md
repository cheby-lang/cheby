# E0026: more than one `_` in one argument list

A function capture has exactly one `_`, and makes a one-parameter function (§5.6, D-202). A call with two or more `_` arguments is an error, because the order in which they would be filled is not obvious.

Example:

```cheby
import std::int

fn adder() -> fn(Int, Int) -> Int {
  int::add(_, _)
}
```

Use the function itself, or write a closure:

```cheby
import std::int

fn adder() -> fn(Int, Int) -> Int {
  int::add
}
```
