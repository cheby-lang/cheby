# E0081: constant that holds a key whose default value holds a function, a `dyn` value or a handle

A constant's value is computed at compile time and embedded in the program, so it cannot hold a function, a `dyn` value or a handle (§4.5, D-139, D-237). For most constants the declared type already says so, and the type check reports E0068. A context key is the exception: the check does not look inside the type argument of `context::Key<T>`, wherever the key appears in the constant's type, because a key of a type that holds functions or `dyn` values is useful as long as its default holds none. `std::time::clock` is a `context::Key<time::Clock>` whose default is the system clock (D-1578, D-1591).

So the default value itself is checked, when the constant is evaluated. A constant whose value holds a key whose default holds a function, such as a clock made by `time::custom_clock`, a `dyn` value, or a handle, such as a channel end or a value of an external type, is this error, reported at the constant's name. The message and the note name what the default holds. Each such constant is reported, also a constant initialized from another key constant (D-1578, D-1589, D-1600).

A `dyn` value carries the function table of its interface, so it cannot be embedded any more than a function can (D-237). `const pet: context::Key<dyn Named> = context::key(Cat)` is this error, and so is a default of type `List<dyn Named>` that holds one. A default that holds no `dyn` value, such as `context::key([])` for a `context::Key<List<dyn Named>>`, is not.

Since it is found by evaluation, `cheby check` reports this error only when the front end found no errors, and the language server reports it after it has been idle (D-459).

Example:

```cheby
import std::context

type Greeter {
  Greeter { greet: fn(String) -> String },
}

fn shout(name: String) -> String {
  "HELLO {name}"
}

const greeter: context::Key<Greeter> = context::key(Greeter { greet: shout })
```

Give the key a default that holds no function, such as `None` with `context::key_without_default`, and provide the value at run time:

```cheby
import std::context

type Greeter {
  Greeter { greet: fn(String) -> String },
}

fn shout(name: String) -> String {
  "HELLO {name}"
}

const greeter: context::Key<Option<Greeter>> = context::key_without_default()

pub fn shouting<R>(body: fn() -> R) -> R {
  context::provide(greeter, Some(Greeter { greet: shout }), body)
}
```
