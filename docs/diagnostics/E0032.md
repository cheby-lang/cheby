# E0032: misplaced rest pattern

A list pattern has at most one rest `..` or `..name`, in any position, so matching is never ambiguous (D-158). In a constructor pattern with named fields, `..` ignores the remaining fields: it comes last, and takes no name (§6.1, §6.4).

Example:

```cheby
fn first_or_zero(items: List<Int>) -> Int {
  case items {
    [first, ..middle, ..rest] => first
    _ => 0
  }
}
```

Use one rest:

```cheby
fn first_or_zero(items: List<Int>) -> Int {
  case items {
    [first, ..] => first
    _ => 0
  }
}
```
