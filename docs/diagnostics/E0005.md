# E0005: identifier with a non-ASCII character

Identifiers are ASCII only (D-127). A word that starts with a non-ASCII letter, such as `été`, is reported once as a whole (D-432). This keeps the case rules of the naming convention unambiguous (D-059) and rules out names that look alike but differ.

Example:

```cheby
fn status() -> String {
  let café = "open"
  café
}
```

Spell the name with ASCII letters:

```cheby
fn status() -> String {
  let cafe = "open"
  cafe
}
```

Strings and comments may contain any Unicode text.
