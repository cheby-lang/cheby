# E0044: binding that reuses a name already in scope

Cheby has no shadowing: a name always means one value within its scope (§5.2.3, D-051). A `let`, a parameter or a pattern binding must not reuse the name of an earlier binding in an enclosing scope, a top-level function or constant of the module, or an imported module (D-062).

Example:

```cheby
import std::io

fn main() {
  let name = "Ada"
  let name = "Grace"
  let io = "stdout"
  io::println(name)
}
```

Give each binding its own name:

```cheby
import std::io

fn main() {
  let first = "Ada"
  let second = "Grace"
  io::println(first)
  io::println(second)
}
```
