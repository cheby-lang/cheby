# E0046: function without a body or an `@external`

A top-level function needs a body. A function without one is allowed only when it has an `@external` attribute that names its foreign implementation (§4.2, §12.5, D-030).

Example:

```cheby
pub fn now() -> Int
```

Add a body, or bind the function to a foreign symbol:

```cheby
@external(native, "cheby_now")
pub fn now() -> Int
```
