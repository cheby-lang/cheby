# E0027: call whose only argument is `_`

`f(_)` means exactly `f`, so it is an error everywhere, not only after a pipe (D-245). There is one way to write it: the function's name. In a pipe, a one-parameter function is written bare: `xs |> list::length`.

Example:

```cheby
import std::list
import std::string

fn shout_all(words: List<String>) -> List<String> {
  list::map(words, string::uppercase(_))
}
```

Pass the function itself:

```cheby
import std::list
import std::string

fn shout_all(words: List<String>) -> List<String> {
  list::map(words, string::uppercase)
}
```
