# E0047: mismatched types

An expression has a different type from the one its context expects (§3.12.5). The message names both types, for example a `String` argument passed where the function's signature says `Int`.

Two checks without a code of their own use this one (D-495). The operands of `&&`, `||` and `!` must be `Bool`, and the label says so on the operator (§5.4.5). A `use` must have as many binders as the callback that its function takes has parameters (§5.10).

Example:

```cheby
fn twice(n: Int) -> Int {
  n * 2
}

fn main() {
  let x = twice("2")
}
```

Pass a value of the expected type:

```cheby
fn twice(n: Int) -> Int {
  n * 2
}

fn main() {
  let x = twice(2)
}
```
