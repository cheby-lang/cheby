# E0015: unclosed delimiter

A `(`, `[`, `{` or the `<` of type arguments has no matching closing delimiter. The secondary label points to the delimiter that is never closed, and the primary label to where the closing one was expected.

Example:

```cheby
import std::io

fn main() {
  io::println("hello"
}
```

A `const` inside a body, as in JavaScript, ends the body here, since `const` starts an item: the help says to write `let`, with an edit (D-1930, D-1931).

Close the call:

```cheby
import std::io

fn main() {
  io::println("hello")
}
```
