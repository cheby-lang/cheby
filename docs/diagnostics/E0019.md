# E0019: attribute not attached to an item

An attribute is `@` followed directly by its name, on its own line before an item (§2.7, §4.8). Here the attribute is followed by no item, for example at the end of the file or before an import, or there is a space between `@` and the name.

Example:

```cheby
pub fn start() {
  Nil
}

@deprecated("use `run` instead")
```

Put the attribute directly before the item it applies to:

```cheby
@deprecated("use `run` instead")
pub fn start() {
  Nil
}
```
