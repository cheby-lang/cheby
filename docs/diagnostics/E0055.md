# E0055: native symbol reserved for the toolchain

The Cheby runtime and the code the compiler generates use C symbols of their own: the runtime's internal functions and data start with `cheby_rt_`, and generated functions, slots and constants start with `cb$`. These symbols have signatures and rules that only the compiler knows, so an `@external(native, …)` outside the standard library must not name them (§12.5, D-455).

Example:

```cheby
@external(native, "cheby_rt_drop")
fn release(text: String)
```

Bind your own C function instead, with a name outside these prefixes:

```cheby
@external(native, "store_release")
fn release(text: String)
```
