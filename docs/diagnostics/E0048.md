# E0048: call with the wrong number of arguments

A call must pass exactly one argument for each parameter of the function (§5.5). Cheby has no default or variadic parameters.

A constructor pattern with the wrong number of fields is this error too, as with fields on a unit constructor or none on a positional one (§6.4, D-495).

Example:

```cheby
fn add(a: Int, b: Int) -> Int {
  a + b
}

fn main() {
  let x = add(1)
}
```

Pass every argument:

```cheby
fn add(a: Int, b: Int) -> Int {
  a + b
}

fn main() {
  let x = add(1, 2)
}
```
