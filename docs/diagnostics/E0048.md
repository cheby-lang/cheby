# E0048: call with the wrong number of arguments

A call must pass exactly one argument for each parameter of the function (§5.6). Cheby has no default or variadic parameters.

Example:

```cheby
fn add(a: Int, b: Int) -> Int {
  a + b
}

fn main() {
  let x = add(1)
}
```

Pass every argument:

```cheby
fn add(a: Int, b: Int) -> Int {
  a + b
}

fn main() {
  let x = add(1, 2)
}
```
