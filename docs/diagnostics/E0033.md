# E0033: float literal pattern

Patterns cannot match float literals (D-113). Float equality treats `0.0` and `-0.0` as equal and makes `NaN` equal to itself (D-069), so a literal pattern would be misleading. Compare in a guard or in a subjectless `case` instead.

Example:

```cheby
fn describe(x: Float) -> String {
  case x {
    0.0 => "zero"
    _ => "other"
  }
}
```

Compare explicitly:

```cheby
fn describe(x: Float) -> String {
  case {
    x == 0.0 => "zero"
    _ => "other"
  }
}
```
