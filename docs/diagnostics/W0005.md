# W0005: package-visible item that nothing in the package uses

An item without a visibility keyword is visible in every module of its package and nowhere else, so when no module of the package uses it, nothing can (§13.8, D-080, D-152). `pub` items are never reported, since other packages may use them, and neither is `main`. Uses of an item inside its own declaration, such as a recursive call, do not count, while uses from tests do.

This warning needs the whole package, so it is computed in a separate pass after type checking (D-266). `cheby check` reports it, and `cheby run` does not wait for it.

Example, where `src/geometry.cheby` declares a function that no module of the package calls:

```cheby
//! Areas of shapes.

fn unit_area() -> Float {
  1.0
}

pub fn square_area(side: Float) -> Float {
  side * side
}
```

Remove the item, use it, or make it `pub` if it is meant for other packages:

```cheby
//! Areas of shapes.

pub fn square_area(side: Float) -> Float {
  side * side
}
```
