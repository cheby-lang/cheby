# E0065: conversion to `dyn` of a value whose type mentions an unbounded type parameter

Every `dyn` value carries a descriptor of its value's full type, so that `==` and hashing can tell values of different types apart (§8.6.1, D-236). For a type parameter `T` of the enclosing function, the descriptor comes from one of `T`'s bounds, so a value whose type mentions `T` can become a `dyn` value only when `T` has a bound. An empty interface is enough (D-237). Type parameters without bounds stay fully parametric.

The same holds where a value whose type mentions `T` is passed to a function that requires a bound, such as `keep<A: Any>(value)` called from a function with an unbounded `T`. The dictionary passed for the bound carries the descriptor of its type, which the callee uses for its own conversions to `dyn` (§8.5.1, D-236).

Example:

```cheby
interface Any

fn boxed<T>(value: T) -> dyn Any {
  value
}
```

Add a bound to the type parameter:

```cheby
interface Any

fn boxed<T: Any>(value: T) -> dyn Any {
  value
}
```
