# E0002: carriage return not followed by a line feed

A line ends with a line feed (`LF`, `U+000A`) or with a carriage return and a line feed (`CRLF`) (§2.1). A carriage return (`CR`, `U+000D`) anywhere else is an error, inside or outside strings and comments.

A stray `CR` usually comes from a file with old Mac line endings, or from text pasted from another program. Convert the file's line endings to `LF` or `CRLF`. To put a carriage return in a string, write the escape `\r` (D-114).
