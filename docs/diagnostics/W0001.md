# W0001: tuple type that hides meaning

A written tuple type that has a tuple as an element, or four or more elements, is a warning (D-243). Such tuples are where positional meaning gets lost: the reader has to remember what each position holds. A type with named fields says it in the code.

The warning applies wherever a type is written: signatures, annotations, aliases and fields. It is reported once per written type, on the outermost tuple that has such a shape, so `(((A, B), C), D)` warns once (D-440).

Example:

```cheby
fn corners() -> ((Int, Int), (Int, Int)) {
  ((0, 0), (1, 1))
}
```

Name the parts:

```cheby
type Point {
  x: Int,
  y: Int,
}

fn corners() -> (Point, Point) {
  (Point { x: 0, y: 0 }, Point { x: 1, y: 1 })
}
```
