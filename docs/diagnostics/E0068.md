# E0068: constant whose type contains a function, `dyn`, or an external or handle type

A constant's value is computed at compile time and embedded in the program (§4.5, D-090). A value that contains a function, including a reference to a top-level function, a channel, a fiber or a value of an external type cannot be baked into a binary meaningfully, so a constant's declared type must not contain such types (D-139). The handles of the standard library, `channel::Sender`, `channel::Receiver`, `fiber::Scope`, `fiber::Fiber` and `selector::Selector`, are external types of their modules, so this rule covers them (D-647). A `duration::Duration` is a plain record and may be a constant (D-650). The check looks through tuples, built-in collections and the fields of every constructor of a named type, so `Option<Db>` and a record with a function field are rejected too. A type argument that no field uses is not looked at (D-511). In v1 it must not contain `dyn` either, because a `dyn` value carries a function table (D-237).

Example:

```cheby
fn double(n: Int) -> Int {
  n * 2
}

const step: fn(Int) -> Int = double
```

Use the function directly, or declare another function:

```cheby
fn double(n: Int) -> Int {
  n * 2
}

fn step(n: Int) -> Int {
  double(n)
}
```
