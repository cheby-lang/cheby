# W0014: imports that are not in `cheby fmt`'s blocks and order

A file's imports come in at most three blocks, with one blank line between two blocks: the modules of the standard library, then the modules of other packages, then the modules of the file's own package. Inside a block the imports are sorted by module path (§13.7, D-1953). `cheby fmt` writes the imports this way, and the compiler warns about a file that is not in this form, so that the rule is seen without running the formatter (§13.8).

A file gets one warning, at the first import that is out of place. `cheby check --fix` and `cheby fmt` both put the imports in order. A comment on the lines above an import, or at the end of its line, moves with the import.

Example, in the package `shop`:

```cheby
import shop::cart
import std::io
import std::list
```

Put the standard library's imports first, and a blank line before the package's own:

```cheby
import std::io
import std::list

import shop::cart
```
