# E0043: item that is not visible from this module

Every item has a visibility (§7.3, D-162). A `priv` item is visible only in its own module, an item without a visibility keyword in every module of its package, and a `pub` item everywhere. An item that is not visible cannot be named, whether qualified or through an item import.

The same code reports a use of the constructors or fields of an opaque type from another package, at the written name, with the note "a `pub` type hides its constructors unless it is `pub exposed`" (§4.3.4, D-048, D-487).

Example, where `src/web.cheby` in package `my_app` declares `priv fn hash_token(token: String) -> String`:

```cheby
import my_app::web

fn main() {
  let hashed = web::hash_token("secret")
}
```

Use an item that the module makes visible, or, if you own the module, remove `priv` from the item so the rest of the package can use it.
