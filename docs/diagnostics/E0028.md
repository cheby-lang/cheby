# E0028: pipe into a call without a `_`

`x |> rhs` has two forms (D-244). If `rhs` is a call with a `_` as a whole argument, `x` fills that `_`. Any other `rhs` is a function that is called with `x` alone. A call without a `_` on the right side is an error, so the reader always sees where the value goes.

A `_` nested in another argument belongs to that inner call (D-202), so `x |> f(a, g(_, b))` also has no hole.

Example:

```cheby
import std::list

fn first_three(numbers: List<Int>) -> List<Int> {
  numbers
  |> list::take(3)
}
```

Add `_` where the piped value goes:

```cheby
import std::list

fn first_three(numbers: List<Int>) -> List<Int> {
  numbers
  |> list::take(_, 3)
}
```

To pipe into a function that a call returns, put the call in parentheses: `x |> (make_handler(config))`.
