# E0045: unknown, malformed, duplicated or misplaced attribute

The set of attributes is fixed (§4.8, D-200, D-461): `@external`, `@target`, `@blocking`, `@async` and `@deprecated`, plus the inner attribute `@!target` for a whole module. This error reports an attribute with an unknown name, with the wrong arguments, given twice, or placed on an item it does not apply to. Only items take attributes: a run of attributes on a variant, a record field or an interface function is also this error, reported once by the parser (D-514). `@external` may appear once per target (§12.5). It also reports an item that exists on no target: a `@target` that contradicts the module's `@!target`, or a function without a body whose `@external` attributes miss every target left to it (§12.6, D-513).

The standard library's own attributes, `@std_clamped` and `@std_hooks`, are unknown attributes outside package `std`, and inside it a misplaced one or one that breaks their rules is this error too (§4.8, D-482).

Example:

```cheby
@extern(native, "cheby_now")
pub fn now() -> Int

@external(native, "a")
@external(native, "b")
pub fn twice() -> Int
```

Use a known attribute with its documented arguments, once per target:

```cheby
@external(native, "cheby_now")
pub fn now() -> Int

@external(native, "a")
@external(js, "./twice.mjs", "twice")
pub fn twice() -> Int
```
