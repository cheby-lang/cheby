# E0045: unknown, malformed, duplicated or misplaced attribute

The set of attributes is fixed (§4.8, D-200, D-461): `@external`, `@target`, `@blocking`, `@async` and `@deprecated`, plus the inner attribute `@!target` for a whole module. This error reports an attribute with an unknown name, with the wrong arguments, given twice, or placed on an item it does not apply to. `@external` may appear once per target (§12.5).

Example:

```cheby
@extern(native, "cheby_now")
pub fn now() -> Int

@external(native, "a")
@external(native, "b")
pub fn twice() -> Int
```

Use a known attribute with its documented arguments, once per target:

```cheby
@external(native, "cheby_now")
pub fn now() -> Int

@external(native, "a")
@external(js, "./twice.mjs", "twice")
pub fn twice() -> Int
```
