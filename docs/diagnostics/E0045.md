# E0045: unknown, malformed, duplicated or misplaced attribute

The set of attributes is fixed (§4.8, D-200, D-461): `@external`, `@target`, `@blocking`, `@async` and `@deprecated`, plus the inner attribute `@!target` for a whole module. This error reports an attribute with an unknown name, with the wrong arguments, given twice, or placed on an item it does not apply to. Only items take attributes: a run of attributes on a variant, a record field or an interface function is also this error, reported once by the parser (D-514). `@external` may appear once per target (§12.5). It also reports an item that exists on no target: a `@target` that contradicts the module's `@!target`, or a function without a body whose `@external` attributes miss every target left to it (§12.6, D-513). And it reports a bound on a type parameter of a function with an `@external`, with or without a body, at the bound: a bound passes a function package and a type descriptor, which have no foreign ABI (§12.5, D-207, D-554).

The standard library's own attributes, `@std_clamped`, `@std_hooks` and `@std_context`, are unknown attributes outside package `std`, and inside it a misplaced one or one that breaks their rules is this error too (§4.8, D-482, D-692). One of those rules is that a function must not have both `@std_context` and `@blocking`: a blocking kernel runs on a thread of the blocking pool, which must never receive a fiber's context. In either order, the function keeps `@blocking` and loses `@std_context`, and the diagnostic points at both attributes (§4.8, §10.9, §12.7, D-191, D-819).

Example:

```cheby
@extern(native, "cheby_now")
pub fn now() -> Int

@external(native, "a")
@external(native, "b")
pub fn twice() -> Int

@external(native, "app_store_put")
pub fn put<T: Show>(key: String, value: T) -> Bool
```

Use a known attribute with its documented arguments, once per target:

```cheby
@external(native, "cheby_now")
pub fn now() -> Int

@external(native, "a")
@external(js, "./twice.mjs", "twice")
pub fn twice() -> Int

@external(native, "app_store_put")
pub fn put<T>(key: String, value: T) -> Bool
```
