# E0060: refutable pattern where an irrefutable one is required

A `let`, a `use` binder and a parameter of a closure or local function take a pattern that must match every value of its type (§6.1, D-242). A pattern that can fail, such as `Some(x)`, a literal, a variant of a type with several variants or a list of a fixed length, is refutable and is this error there. The message shows a value that the pattern does not match.

Use `case` to handle the other values, or `let assert` when a mismatch is a bug and should panic (D-159).

Example:

```cheby
fn first_or_zero(xs: List<Int>) -> Int {
  let [first, ..] = xs
  first
}
```

`[first, ..]` does not match the empty list. Handle it with `case`:

```cheby
fn first_or_zero(xs: List<Int>) -> Int {
  case xs {
    [first, ..] => first
    [] => 0
  }
}
```
