# E0022: `exposed` without `pub` or on something other than a type

`exposed` makes a type's constructors and fields usable from other packages (D-035, D-048). It applies only to type declarations, and only together with `pub`, because a type that other packages cannot see has nothing to expose (D-150). It is not allowed on type aliases, functions, constants or interfaces.

Example:

```cheby
exposed type Point {
  x: Int,
  y: Int,
}
```

Make the type `pub` as well:

```cheby
pub exposed type Point {
  x: Int,
  y: Int,
}
```
