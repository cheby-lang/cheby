# E0021: pattern as a top-level function parameter

Parameters of top-level functions are plain names (D-242). The names document the function's signature and show up in hover and generated documentation. Closures and local functions may take patterns.

Example:

```cheby
fn sum_pair((a, b): (Int, Int)) -> Int {
  a + b
}
```

Name the parameter and take it apart in the body:

```cheby
fn sum_pair(pair: (Int, Int)) -> Int {
  let (a, b) = pair
  a + b
}
```
