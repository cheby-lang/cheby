# E0077: constant whose evaluation reached an external function or effect it may not use

Constant evaluation must give the same value on every build, so an initializer may not perform input or output, read the environment, the clock or randomness, or call foreign code (§4.5, §13.9, D-090). Effects are not tracked by types (D-016), so this is found while the constant is evaluated: reaching any `@external` function is an error, except the effect-free kernels of `std::list`, `std::map`, `std::set`, `std::string`, `std::bytes` and the numeric modules `std::int`, `std::float`, `std::f32` and the sized integer modules (D-360, D-537). The error points at the constant whose initializer reached the function, which may be a constant that the first one read, and a note names what evaluation reached: "it reached the external function `<symbol>`; only the kernels of `std::list`, `std::map`, `std::set`, `std::string`, `std::bytes` and the numeric modules run at compile time". `<symbol>` is the native symbol, such as `cheby_io_println`, or the path of a function that has only a JS implementation, which a constant that exists on `js` may call (§12.5, D-591, D-592).

`cheby check` also reports this error when a constant calls a native function that nothing in the build defines, because it cannot run it (D-532). The note then says "it called a native function that nothing in this build defines" (D-592). `cheby check` reports nothing for such a function that constants never call; `cheby run` reports it as E0053.

Example:

```cheby
import std::io

const greeting: String = announce("hello")

fn announce(text: String) -> String {
  io::println(text)
  text
}
```

Compute the value without the effect, and perform the effect at run time:

```cheby
import std::io

const greeting: String = "hello"

fn main() {
  io::println(greeting)
}
```
