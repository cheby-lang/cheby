# E0016: code nested too deeply

The parser limits how deeply expressions, patterns, types and blocks may nest, so that it never runs out of stack on any input. Expressions, patterns, types and blocks share one count, and the limit is 256 levels, far more than readable code needs. A block used as an expression counts once, and the body of a function, closure, local function or test counts as a level of its own (D-441). A chain of operators, calls or field accesses, such as `a + b + c` or `x.a.b`, nests its left part one level per step, so a very long chain counts as deep code too.

Code this deep is usually generated. Name intermediate results with `let`, or split the code into functions.
