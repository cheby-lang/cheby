# E0016: code nested too deeply

The parser limits how deeply expressions, patterns, types and blocks may nest, so that it never runs out of stack on any input. Expressions, patterns, types and blocks share one count, and the limit is 256 levels, far more than readable code needs. A block used as an expression counts once, and the body of a function, closure, local function or test counts as a level of its own (D-441).

Code this deep is usually generated. Name intermediate results with `let`, or split the code into functions.
