# E0074: signature that mentions a type or interface less visible than its item

An item's signature must not mention a type that is less visible than the item itself (§4.1.3, §7.4, D-148, D-149). Code that can see the item could not name the type, so it could not write a parameter or a variable for it. A `pub` item must mention only `pub` types, and a package-visible item must not mention a `priv` type. The same holds for the interfaces named in bounds, in `dyn` types and in embeddings.

The signature of a function is its parameter types, its return type and its bounds. The signature of a constant is its declared type, that of an alias its definition, and that of an interface its embedded interfaces and its functions. The fields of a type count where they are visible (§4.3.4, D-198): a `pub exposed` type's fields must mention only `pub` types, while a `pub` type without `exposed` may have fields of package-visible types, because its representation is hidden outside the package.

An alias is transparent (D-081), so what counts is the type it stands for, and the alias's own visibility does not matter: a `pub` function may use a package-visible alias of `Int`, but not one of a package-visible type (D-488). The error is reported once per item and offending type, at the first mention, with a label at the type's declaration (D-488). Its help offers two fixes that each work alone: make the type as visible as the item needs, or make the item as visible as the type (D-636). A `pub` function `reveal` that mentions a `priv` type `Secret` gets "make `Secret` `pub`, or make `reveal` `priv`", since a package-visible function could not mention it either, and one that mentions a package-visible type `Shared` gets "make `Shared` `pub`, or make `reveal` package-visible". For the fields of a `pub exposed` type `Envelope`, the help is "make `Secret` `pub`, or make `Envelope` `priv`" when the field type is `priv`, because without `exposed` the fields still must not mention a `priv` type, and "make `Shared` `pub`, or remove `exposed` from `Envelope`" when it is package-visible. For the fields of a type that is not `exposed`, it is "make `Secret` package-visible, or make `Envelope` `priv`" (D-636).

Example:

```cheby
type Token {
  Token(String),
}

pub fn issue(text: String) -> Token {
  Token(text)
}
```

Make the type as visible as the item, or make the item less visible:

```cheby
pub type Token {
  Token(String),
}

pub fn issue(text: String) -> Token {
  Token(text)
}
```
