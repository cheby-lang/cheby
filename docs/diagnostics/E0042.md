# E0042: name that does not refer to anything usable here

A name must refer to something in scope (§7.7). An unqualified name is a local binding or parameter, an item of the current module, a name brought in by an import, or a prelude name. A qualified name `m::x` needs `m` to be an imported module and `x` to be an item of it. A module name is not a value on its own. `Self` names a type only inside an interface declaration, and elsewhere it is reported with this code (§8.1, D-462).

Every module must be imported before use, including standard-library modules (§7.5.2, D-060).

Example:

```cheby
import std::io

fn main() {
  let message = "hello"
  io::println(mesage)
  list::length([1, 2])
}
```

Fix the spelling and import the module:

```cheby
import std::io
import std::list

fn main() {
  let message = "hello"
  io::println(message)
  let n = list::length([1, 2])
  io::println("{n}")
}
```
