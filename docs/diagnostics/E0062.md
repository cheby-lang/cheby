# E0062: alternatives of a pattern that bind different names

The alternatives of a pattern `p1 | p2` must bind the same names, each with the same type (§6.7). The arm's body uses those names, and they must have a value whichever alternative matched. The message names all the bindings that are missing from an alternative, as in "this alternative does not bind `x` and `y`", with a label where each is bound, and each alternative gets one error. A name bound twice in one pattern is E0044 instead (D-506).

Example:

```cheby
type Shape {
  Circle(Float),
  Square(Float),
  Dot,
}

fn length(shape: Shape) -> Float {
  case shape {
    Circle(radius) | Square(side) => radius
    Dot => 0.0
  }
}
```

Bind the same name in every alternative:

```cheby
type Shape {
  Circle(Float),
  Square(Float),
  Dot,
}

fn length(shape: Shape) -> Float {
  case shape {
    Circle(size) | Square(size) => size
    Dot => 0.0
  }
}
```
