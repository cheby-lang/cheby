# W0004: unused `priv` item

A `priv` item is visible only in its own module, so when nothing in that module uses it, nothing can (§13.8, D-080, D-152). The item is dead code, or a use of it is missing. Uses of an item inside its own declaration, such as a recursive call, do not count. A type counts as used when its name or one of its constructors is used, and a function that satisfies an interface counts as used when the interface is used through it, for example by an interpolation. Constructors are never reported on their own. Items whose names start with `_` are reported too, since the exemption of §2.3 covers bindings only. The warning is reported only when every body of the module type-checked, because the uses in a body with an error are not known (§13.8, D-516).

Example:

```cheby
priv fn twice(n: Int) -> Int {
  n * 2
}

pub fn answer() -> Int {
  42
}
```

Remove the item, or use it:

```cheby
priv fn twice(n: Int) -> Int {
  n * 2
}

pub fn answer() -> Int {
  twice(21)
}
```
