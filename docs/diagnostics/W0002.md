# W0002: unused local binding or parameter

A `let` binding, a pattern binding or a parameter that is never used is a warning (§13.8, D-080). An unused binding is often a sign of a mistake, such as a computed value that was meant to be returned. It is a warning rather than an error so that half-finished code still runs, and `--deny-warnings` turns it into an error for CI.

A binding whose name starts with `_` is never reported (§2.3), and `_` itself binds nothing. A local function that only calls itself is unused (D-516). This warning needs only name resolution, so it is reported even when a body has type errors (D-516).

Example:

```cheby
fn area(width: Int, height: Int) -> Int {
  let perimeter = 2 * (width + height)
  width * height
}
```

Remove the binding, use it, or start its name with `_`:

```cheby
fn area(width: Int, height: Int) -> Int {
  width * height
}
```
