# E0052: interface where a type is expected, or a type where an interface is expected

An interface is not a type (§8.1, D-462). A value whose type is only known to satisfy an interface has the type `dyn Interface` (§8.6), and a function that works for every type satisfying it takes a bounded type parameter (§8.4). The reverse also holds: only an interface may follow `dyn`.

Example:

```cheby
fn describe(value: Show) -> String {
  Show::show(value)
}

fn wrap(value: dyn Int) -> String {
  "?"
}
```

Write `dyn` before an interface, or use a type parameter with a bound:

```cheby
fn describe(value: dyn Show) -> String {
  Show::show(value)
}

fn describe_any<T: Show>(value: T) -> String {
  Show::show(value)
}
```
