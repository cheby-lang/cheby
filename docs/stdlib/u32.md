# `std::u32`

The module of the built-in `U32` type, an unsigned 32-bit integer (§3.3.3, D-105). `U32` is in the prelude (D-112), and this module is where the type is declared (§8.2):

```cheby
pub type U32
```

A `U32` holds the integers from 0 to 4294967295. Arithmetic is checked at that width, so a result outside the range panics (D-025). On JS it is a number checked to this range (§12.3.3), so `U32` behaves the same on every target (D-106).

The functions of this module are the integer families of [Numeric modules](README.md#numeric-modules), which define them for every integer type. The table below lists each function with its signature and family, and the examples show one family each (D-350). `compare`, `show` and the arithmetic functions make `U32` satisfy `Compare`, `Show`, `Add`, `Sub`, `Mul`, `Div` and `Neg` (§8.7, §8.8).

There is no conversion from `Float` or `F32`. A float becomes a `U32` through a rounding function such as `float::truncate` and then `u32::from_int` (D-359). The conversions from `U32` to other types are in their modules, such as `int::from_u32` and `float::from_u32`. The bitwise operators are built in (§5.4.6), so there are no functions for them, and the functions `std::int` has outside the families are not repeated here (D-389, D-391).

`U32` has no negative values, so `neg` and `checked_neg` succeed only for 0, `abs` returns its argument, and `wrapping_neg(n)` is 2³² − n for every other `n`.

Every function costs O(1), except `parse` and `parse_base`, which cost O(n) in the length of the text. The costs are informative.

## Examples

### Constants

```cheby
test "the u32 range" {
  assert u32::min_value == 0
  assert u32::max_value == 4_294_967_295
}
```

### Conversions

```cheby
test "conversions to u32" {
  assert u32::from_u8(255) == 255
  assert u32::from_u16(65535) == 65535
  assert u32::from_int(4_294_967_295) == Ok(4_294_967_295)
  assert u32::from_int(-1) == Err(Nil)
  assert u32::from_u64(4_294_967_296) == Err(Nil)
}
```

### Parsing and text

```cheby
test "u32 parses and shows decimal digits" {
  let small: U32 = 7
  assert u32::parse("4294967295") == Ok(4_294_967_295)
  assert u32::parse("-1") == Err(Nil)
  assert u32::parse_base("ffffffff", 16) == Ok(u32::max_value)
  assert u32::show(u32::max_value) == "4294967295"
  assert "{small}" == "7"
}
```

### Comparison

```cheby
test "comparing u32 values" {
  assert u32::compare(1, 2) == Less
  assert u32::compare(3, 3) == Equal
  assert u32::min(100, 7) == 7
  assert u32::max(100, 7) == 100
}
```

### Arithmetic

```cheby
test "u32 operators as functions" {
  assert u32::add(200, 55) == 255
  assert u32::sub(7, 2) == 5
  assert u32::mul(15, 17) == 255
  assert u32::div(7, 2) == 3
  assert u32::rem(7, 2) == 1
  assert u32::neg(0) == 0
  assert u32::abs(7) == 7
}
```

### Checked arithmetic

```cheby
test "u32 checked arithmetic reports overflow" {
  assert u32::checked_add(200, 55) == Ok(255)
  assert u32::checked_add(u32::max_value, 1) == Err(Nil)
  assert u32::checked_sub(0, 1) == Err(Nil)
  assert u32::checked_mul(u32::max_value, 2) == Err(Nil)
  assert u32::checked_div(7, 0) == Err(Nil)
  assert u32::checked_rem(7, 2) == Ok(1)
  assert u32::checked_neg(0) == Ok(0)
  assert u32::checked_neg(1) == Err(Nil)
}
```

### Wrapping arithmetic

```cheby
test "u32 wrapping arithmetic wraps around" {
  assert u32::wrapping_add(u32::max_value, 1) == 0
  assert u32::wrapping_sub(0, 1) == u32::max_value
  assert u32::wrapping_mul(u32::max_value, 2) == u32::max_value - 1
  assert u32::wrapping_neg(1) == u32::max_value
}
```
