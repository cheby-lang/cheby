# `std::i16`

The module of the built-in `I16` type, a signed 16-bit integer (§3.3.3, D-105). `I16` is in the prelude (D-112), and this module is where the type is declared (§8.2):

```cheby
pub type I16
```

An `I16` holds the integers from −32768 to 32767. Arithmetic is checked at that width, so a result outside the range panics (D-025). On JS it is a number checked to this range (§12.3.3), so `I16` behaves the same on every target (D-106).

The functions of this module are the integer families of [Numeric modules](README.md#numeric-modules), which define them for every integer type. The table below lists each function with its signature and family, and the examples show one family each (D-350). `compare`, `show` and the arithmetic functions make `I16` satisfy `Compare`, `Show`, `Add`, `Sub`, `Mul`, `Div` and `Neg` (§8.7, §8.8).

There is no conversion from `Float` or `F32`. A float becomes an `I16` through a rounding function such as `float::truncate` and then `i16::from_int` (D-359). The conversions from `I16` to other types are in their modules, such as `int::from_i16` and `float::from_i16`. The bitwise operators are built in (§5.4.6), so there are no functions for them, and the functions `std::int` has outside the families are not repeated here (D-389, D-391).

Every function costs O(1), except `parse` and `parse_base`, which cost O(n) in the length of the text. The costs are informative.

## Examples

### Constants

```cheby
test "the i16 range" {
  assert i16::min_value == -32_768
  assert i16::max_value == 32_767
}
```

### Conversions

```cheby
test "conversions to i16" {
  assert i16::from_i8(-128) == -128
  assert i16::from_u8(255) == 255
  assert i16::from_int(32768) == Err(Nil)
  assert i16::from_i32(-32768) == Ok(-32768)
  assert i16::from_u16(65535) == Err(Nil)
}
```

### Parsing and text

```cheby
test "i16 parses and shows decimal digits" {
  let small: I16 = -5
  assert i16::parse("-32768") == Ok(-32768)
  assert i16::parse("32768") == Err(Nil)
  assert i16::parse_base("-1010", 2) == Ok(-10)
  assert i16::show(i16::min_value) == "-32768"
  assert "{small}" == "-5"
}
```

### Comparison

```cheby
test "comparing i16 values" {
  assert i16::compare(-1, 1) == Less
  assert i16::compare(3, 3) == Equal
  assert i16::min(-100, 7) == -100
  assert i16::max(-100, 7) == 7
}
```

### Arithmetic

```cheby
test "i16 operators as functions" {
  assert i16::add(100, 27) == 127
  assert i16::sub(-100, 28) == -128
  assert i16::mul(-4, 5) == -20
  assert i16::div(-7, 2) == -3
  assert i16::rem(-7, 2) == -1
  assert i16::neg(127) == -127
  assert i16::abs(-127) == 127
}
```

### Checked arithmetic

```cheby
test "i16 checked arithmetic reports overflow" {
  assert i16::checked_add(100, 27) == Ok(127)
  assert i16::checked_add(i16::max_value, 1) == Err(Nil)
  assert i16::checked_sub(i16::min_value, 1) == Err(Nil)
  assert i16::checked_mul(i16::max_value, 2) == Err(Nil)
  assert i16::checked_div(i16::min_value, -1) == Err(Nil)
  assert i16::checked_rem(7, 0) == Err(Nil)
  assert i16::checked_neg(i16::min_value) == Err(Nil)
}
```

### Wrapping arithmetic

```cheby
test "i16 wrapping arithmetic wraps around" {
  assert i16::wrapping_add(i16::max_value, 1) == i16::min_value
  assert i16::wrapping_sub(i16::min_value, 1) == i16::max_value
  assert i16::wrapping_mul(i16::max_value, 2) == -2
  assert i16::wrapping_neg(i16::min_value) == i16::min_value
}
```
