# `std::u64`

The module of the built-in `U64` type, an unsigned 64-bit integer (§3.3.3, D-105). `U64` is in the prelude (D-112), and this module is where the type is declared (§8.2):

```cheby
pub type U64
```

A `U64` holds the integers from 0 to 2⁶⁴−1 (18446744073709551615). Arithmetic is checked at that width, so a result outside the range panics (D-025). `U64` is exact on JS too, where it is a `BigInt`, so it behaves the same on every target, although its arithmetic is slower there than `Int`'s (D-106, ADR-0030).

The functions of this module are the integer families of [Numeric modules](README.md#numeric-modules), which define them for every integer type. The table below lists each function with its signature and family, and the examples show one family each (D-350). `compare`, `show` and the arithmetic functions make `U64` satisfy `Compare`, `Show`, `Add`, `Sub`, `Mul`, `Div` and `Neg` (§8.7, §8.8).

There is no conversion from `Float` or `F32`. A float becomes a `U64` through a rounding function such as `float::truncate` and then `u64::from_int` (D-359). The conversions from `U64` to other types are in their modules, such as `int::from_u64` and `float::from_u64`. The bitwise operators are built in (§5.4.6), so there are no functions for them, and the functions `std::int` has outside the families are not repeated here (D-389, D-391).

`U64` has no negative values, so `neg` and `checked_neg` succeed only for 0, `abs` returns its argument, and `wrapping_neg(n)` is 2⁶⁴ − n for every other `n`.

Every function costs O(1), except `parse` and `parse_base`, which cost O(n) in the length of the text. The costs are informative.

## Examples

### Constants

```cheby
test "the u64 range" {
  assert u64::min_value == 0
  assert u64::max_value == 18_446_744_073_709_551_615
}
```

### Conversions

```cheby
test "conversions to u64" {
  assert u64::from_u32(4_294_967_295) == 4_294_967_295
  assert u64::from_int(42) == Ok(42)
  assert u64::from_int(-1) == Err(Nil)
  assert u64::from_i64(i64::max_value) == Ok(9_223_372_036_854_775_807)
}
```

### Parsing and text

```cheby
test "u64 parses and shows decimal digits" {
  let small: U64 = 7
  assert u64::parse("18446744073709551615") == Ok(u64::max_value)
  assert u64::parse("18446744073709551616") == Err(Nil)
  assert u64::parse_base("ffffffffffffffff", 16) == Ok(u64::max_value)
  assert u64::show(u64::max_value) == "18446744073709551615"
  assert "{small}" == "7"
}
```

### Comparison

```cheby
test "comparing u64 values" {
  assert u64::compare(1, 2) == Less
  assert u64::compare(3, 3) == Equal
  assert u64::min(100, 7) == 7
  assert u64::max(100, 7) == 100
}
```

### Arithmetic

```cheby
test "u64 operators as functions" {
  assert u64::add(200, 55) == 255
  assert u64::sub(7, 2) == 5
  assert u64::mul(15, 17) == 255
  assert u64::div(7, 2) == 3
  assert u64::rem(7, 2) == 1
  assert u64::neg(0) == 0
  assert u64::abs(7) == 7
}
```

### Checked arithmetic

```cheby
test "u64 checked arithmetic reports overflow" {
  assert u64::checked_add(200, 55) == Ok(255)
  assert u64::checked_add(u64::max_value, 1) == Err(Nil)
  assert u64::checked_sub(0, 1) == Err(Nil)
  assert u64::checked_mul(u64::max_value, 2) == Err(Nil)
  assert u64::checked_div(7, 0) == Err(Nil)
  assert u64::checked_rem(7, 2) == Ok(1)
  assert u64::checked_neg(0) == Ok(0)
  assert u64::checked_neg(1) == Err(Nil)
}
```

### Wrapping arithmetic

```cheby
test "u64 wrapping arithmetic wraps around" {
  assert u64::wrapping_add(u64::max_value, 1) == 0
  assert u64::wrapping_sub(0, 1) == u64::max_value
  assert u64::wrapping_mul(u64::max_value, 2) == u64::max_value - 1
  assert u64::wrapping_neg(1) == u64::max_value
}
```
