# `std::f32`

The module of the built-in `F32` type, an IEEE 754 binary32 number (§3.3.3, D-105). `F32` is in the prelude (D-112), and this module is where the type is declared (§8.2):

```cheby
pub type F32
```

An `F32` holds the binary32 values: the finite values from −(2−2⁻²³)×2¹²⁷ (about −3.4028235e38) to (2−2⁻²³)×2¹²⁷, `-0.0`, the infinities and NaN. Arithmetic follows IEEE 754 at binary32, rounded to the nearest value with ties to even, and never panics (D-069). Equality and `compare` follow the same rules as on `Float`: `==` is reflexive, `-0.0 == 0.0`, and NaN is `Greater` than every other value (§3.3.3, D-135). On JS an `F32` is a number rounded with `Math.fround` (§12.3.3), so it behaves the same on every target (D-106).

The functions of this module are the float families of [Numeric modules](README.md#numeric-modules), which define them for every float type, plus the conversions to `Int` and the tests for special values of [`std::float`](float.md), which behave as there at binary32. The table below lists each function with its signature and where it is defined, and the examples show one family each (D-350). `compare`, `show` and the arithmetic functions make `F32` satisfy `Compare`, `Show`, `Add`, `Sub`, `Mul`, `Div` and `Neg` (§8.7, §8.8).

`show` writes the shortest text that reads back as the same `F32`, judged at `F32` precision, so `0.1` as an `F32` shows as `0.1` (D-228). Its other rules, including where it switches to an exponent, are those of [`float::show`](float.md#show). `parse` reads the decimal text straight to the nearest `F32`, ties to even, not through a `Float`, so it never rounds twice (D-313).

Every conversion into `F32` succeeds and returns `F32` (D-359). It is exact from `I8`, `I16`, `U8` and `U16`, and rounds to the nearest `F32`, ties to even, from the wider integer types and from `Float`. A `Float` beyond `F32`'s range gives an infinity. `F32` becomes an integer only through `truncate`, `round`, `floor` and `ceil`, which return `Result<Int, Nil>` (D-132). The conversion from `F32` to `Float`, `float::from_f32`, is exact.

`std::f32` has no `clamp`, `sqrt`, `pow` or transcendental functions in tier 1. A program converts with `float::from_f32` and computes in `Float` (D-397).

Every function costs O(1), except `parse`, which costs O(n) in the length of the text. The costs are informative.

## Examples

### Constants

```cheby
test "the f32 constants" {
  assert f32::max_value == 3.4028235e38
  assert f32::max_value * 2.0 == f32::infinity
  assert 1.0 + f32::epsilon > 1.0
  assert f32::nan == f32::nan
  assert f32::neg_infinity < f32::min_value
}
```

### Conversions

```cheby
test "conversions to f32 round to the nearest value" {
  assert f32::from_u8(255) == 255.0
  assert f32::from_int(16_777_217) == 16777216.0
  assert f32::from_float(1.0e300) == f32::infinity
  assert float::from_f32(f32::from_float(0.1)) == 0.10000000149011612
}
```

### Parsing and text

```cheby
test "f32 shows at its own precision" {
  let tenth: F32 = 0.1
  assert "{tenth}" == "0.1"
  assert f32::show(f32::max_value) == "3.4028235e38"
  assert f32::show(f32::neg_infinity) == "-inf"
  assert f32::parse("0.1") == Ok(tenth)
  assert f32::parse("1e3") == Ok(1000.0)
  assert f32::parse(".5") == Err(Nil)
  assert f32::parse(f32::show(f32::epsilon)) == Ok(f32::epsilon)
}
```

### Comparison

```cheby
test "comparing f32 values" {
  assert f32::compare(1.0, 2.0) == Less
  assert f32::compare(-0.0, 0.0) == Equal
  assert f32::compare(f32::nan, f32::infinity) == Greater
  assert f32::min(1.0, f32::nan) == 1.0
  assert f32::max(-1.0, 2.5) == 2.5
}
```

### Arithmetic

```cheby
test "f32 operators as functions" {
  assert f32::add(0.5, 0.25) == 0.75
  assert f32::sub(0.5, 0.25) == 0.25
  assert f32::mul(1.5, -2.0) == -3.0
  assert f32::div(1.0, 0.0) == f32::infinity
  assert f32::rem(-7.5, 2.0) == -1.5
  assert f32::neg(1.5) == -1.5
  assert f32::abs(-1.5) == 1.5
}
```

### Conversion to `Int`

```cheby
test "f32 rounds to an Int" {
  assert f32::truncate(-2.7) == Ok(-2)
  assert f32::round(2.5) == Ok(3)
  assert f32::round(-2.5) == Ok(-3)
  assert f32::floor(-2.5) == Ok(-3)
  assert f32::ceil(2.1) == Ok(3)
  assert f32::truncate(f32::nan) == Err(Nil)
}
```

### Special values

```cheby
test "f32 tests for special values" {
  assert f32::is_nan(f32::nan)
  assert f32::is_infinite(f32::infinity)
  assert f32::is_finite(f32::max_value)
  assert !f32::is_finite(f32::neg_infinity)
}
```
