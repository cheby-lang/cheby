# `std::i32`

The module of the built-in `I32` type, a signed 32-bit integer (§3.3.3, D-105). `I32` is in the prelude (D-112), and this module is where the type is declared (§8.2):

```cheby
pub type I32
```

An `I32` holds the integers from −2147483648 to 2147483647. Arithmetic is checked at that width, so a result outside the range panics (D-025). On JS it is a number checked to this range (§12.3.3), so `I32` behaves the same on every target (D-106).

The functions of this module are the integer families of [Numeric modules](README.md#numeric-modules), which define them for every integer type. The table below lists each function with its signature and family, and the examples show one family each (D-350). `compare`, `show` and the arithmetic functions make `I32` satisfy `Compare`, `Show`, `Add`, `Sub`, `Mul`, `Div` and `Neg` (§8.7, §8.8).

There is no conversion from `Float` or `F32`. A float becomes an `I32` through a rounding function such as `float::truncate` and then `i32::from_int` (D-359). The conversions from `I32` to other types are in their modules, such as `int::from_i32` and `float::from_i32`. The bitwise operators are built in (§5.4.6), so there are no functions for them, and the functions `std::int` has outside the families are not repeated here (D-389, D-391).

Every function costs O(1), except `parse` and `parse_base`, which cost O(n) in the length of the text. The costs are informative.

## Examples

### Constants

```cheby
test "the i32 range" {
  assert i32::min_value == -2_147_483_648
  assert i32::max_value == 2_147_483_647
}
```

### Conversions

```cheby
test "conversions to i32" {
  assert i32::from_i16(-32768) == -32768
  assert i32::from_u16(65535) == 65535
  assert i32::from_int(-2_147_483_649) == Err(Nil)
  assert i32::from_i64(-1) == Ok(-1)
  assert i32::from_u32(4_294_967_295) == Err(Nil)
}
```

### Parsing and text

```cheby
test "i32 parses and shows decimal digits" {
  let small: I32 = -5
  assert i32::parse("2147483647") == Ok(2_147_483_647)
  assert i32::parse("2147483648") == Err(Nil)
  assert i32::parse_base("-80000000", 16) == Ok(-2_147_483_648)
  assert i32::show(i32::max_value) == "2147483647"
  assert "{small}" == "-5"
}
```

### Comparison

```cheby
test "comparing i32 values" {
  assert i32::compare(-1, 1) == Less
  assert i32::compare(3, 3) == Equal
  assert i32::min(-100, 7) == -100
  assert i32::max(-100, 7) == 7
}
```

### Arithmetic

```cheby
test "i32 operators as functions" {
  assert i32::add(100, 27) == 127
  assert i32::sub(-100, 28) == -128
  assert i32::mul(-4, 5) == -20
  assert i32::div(-7, 2) == -3
  assert i32::rem(-7, 2) == -1
  assert i32::neg(127) == -127
  assert i32::abs(-127) == 127
}
```

### Checked arithmetic

```cheby
test "i32 checked arithmetic reports overflow" {
  assert i32::checked_add(100, 27) == Ok(127)
  assert i32::checked_add(i32::max_value, 1) == Err(Nil)
  assert i32::checked_sub(i32::min_value, 1) == Err(Nil)
  assert i32::checked_mul(i32::max_value, 2) == Err(Nil)
  assert i32::checked_div(i32::min_value, -1) == Err(Nil)
  assert i32::checked_rem(7, 0) == Err(Nil)
  assert i32::checked_neg(i32::min_value) == Err(Nil)
}
```

### Wrapping arithmetic

```cheby
test "i32 wrapping arithmetic wraps around" {
  assert i32::wrapping_add(i32::max_value, 1) == i32::min_value
  assert i32::wrapping_sub(i32::min_value, 1) == i32::max_value
  assert i32::wrapping_mul(i32::max_value, 2) == -2
  assert i32::wrapping_neg(i32::min_value) == i32::min_value
}
```
