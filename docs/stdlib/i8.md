# `std::i8`

The module of the built-in `I8` type, a signed 8-bit integer (§3.3.3, D-105). `I8` is in the prelude (D-112), and this module is where the type is declared (§8.2):

```cheby
pub type I8
```

An `I8` holds the integers from −128 to 127. Arithmetic is checked at that width, so a result outside the range panics (D-025). On JS it is a number checked to this range (§12.3.3), so `I8` behaves the same on every target (D-106).

The functions of this module are the integer families of [Numeric modules](README.md#numeric-modules), which define them for every integer type. The table below lists each function with its signature and family, and the examples show one family each (D-350). `compare`, `show` and the arithmetic functions make `I8` satisfy `Compare`, `Show`, `Add`, `Sub`, `Mul`, `Div` and `Neg` (§8.7, §8.8).

There is no conversion from `Float` or `F32`. A float becomes an `I8` through a rounding function such as `float::truncate` and then `i8::from_int` (D-359). The conversions from `I8` to other types are in their modules, such as `int::from_i8` and `float::from_i8`. The bitwise operators are built in (§5.4.6), so there are no functions for them, and the functions `std::int` has outside the families are not repeated here (D-389, D-391).

Every function costs O(1), except `parse` and `parse_base`, which cost O(n) in the length of the text. The costs are informative.

## Examples

### Constants

```cheby
test "the i8 range" {
  assert i8::min_value == -128
  assert i8::max_value == 127
}
```

### Conversions

```cheby
test "conversions to i8" {
  assert i8::from_int(-128) == Ok(-128)
  assert i8::from_int(128) == Err(Nil)
  assert i8::from_i32(-5) == Ok(-5)
  assert i8::from_u8(200) == Err(Nil)
}
```

### Parsing and text

```cheby
test "i8 parses and shows decimal digits" {
  let small: I8 = -5
  assert i8::parse("-128") == Ok(-128)
  assert i8::parse("128") == Err(Nil)
  assert i8::parse("+1") == Err(Nil)
  assert i8::parse_base("7f", 16) == Ok(127)
  assert i8::show(-128) == "-128"
  assert "{small}" == "-5"
}
```

### Comparison

```cheby
test "comparing i8 values" {
  assert i8::compare(-1, 1) == Less
  assert i8::compare(3, 3) == Equal
  assert i8::min(-100, 7) == -100
  assert i8::max(-100, 7) == 7
}
```

### Arithmetic

```cheby
test "i8 operators as functions" {
  assert i8::add(100, 27) == 127
  assert i8::sub(-100, 28) == -128
  assert i8::mul(-4, 5) == -20
  assert i8::div(-7, 2) == -3
  assert i8::rem(-7, 2) == -1
  assert i8::neg(127) == -127
  assert i8::abs(-127) == 127
}
```

### Checked arithmetic

```cheby
test "i8 checked arithmetic reports overflow" {
  assert i8::checked_add(100, 27) == Ok(127)
  assert i8::checked_add(i8::max_value, 1) == Err(Nil)
  assert i8::checked_sub(i8::min_value, 1) == Err(Nil)
  assert i8::checked_mul(i8::max_value, 2) == Err(Nil)
  assert i8::checked_div(i8::min_value, -1) == Err(Nil)
  assert i8::checked_rem(7, 0) == Err(Nil)
  assert i8::checked_neg(i8::min_value) == Err(Nil)
}
```

### Wrapping arithmetic

```cheby
test "i8 wrapping arithmetic wraps around" {
  assert i8::wrapping_add(i8::max_value, 1) == i8::min_value
  assert i8::wrapping_sub(i8::min_value, 1) == i8::max_value
  assert i8::wrapping_mul(i8::max_value, 2) == -2
  assert i8::wrapping_neg(i8::min_value) == i8::min_value
}
```
