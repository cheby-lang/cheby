# `std::u16`

The module of the built-in `U16` type, an unsigned 16-bit integer (§3.3.3, D-105). `U16` is in the prelude (D-112), and this module is where the type is declared (§8.2):

```cheby
pub type U16
```

A `U16` holds the integers from 0 to 65535. Arithmetic is checked at that width, so a result outside the range panics (D-025). On JS it is a number checked to this range (§12.3.3), so `U16` behaves the same on every target (D-106).

The functions of this module are the integer families of [Numeric modules](README.md#numeric-modules), which define them for every integer type. The table below lists each function with its signature and family, and the examples show one family each (D-350). `compare`, `show` and the arithmetic functions make `U16` satisfy `Compare`, `Show`, `Add`, `Sub`, `Mul`, `Div` and `Neg` (§8.7, §8.8).

There is no conversion from `Float` or `F32`. A float becomes a `U16` through a rounding function such as `float::truncate` and then `u16::from_int` (D-359). The conversions from `U16` to other types are in their modules, such as `int::from_u16` and `float::from_u16`. The bitwise operators are built in (§5.4.6), so there are no functions for them, and the functions `std::int` has outside the families are not repeated here (D-389, D-391).

`U16` has no negative values, so `neg` and `checked_neg` succeed only for 0, `abs` returns its argument, and `wrapping_neg(n)` is 2¹⁶ − n for every other `n`.

Every function costs O(1), except `parse` and `parse_base`, which cost O(n) in the length of the text. The costs are informative.

## Examples

### Constants

```cheby
test "the u16 range" {
  assert u16::min_value == 0
  assert u16::max_value == 65_535
}
```

### Conversions

```cheby
test "conversions to u16" {
  assert u16::from_u8(255) == 255
  assert u16::from_u32(65535) == Ok(65535)
  assert u16::from_int(65536) == Err(Nil)
  assert u16::from_i16(-1) == Err(Nil)
}
```

### Parsing and text

```cheby
test "u16 parses and shows decimal digits" {
  let small: U16 = 7
  assert u16::parse("65535") == Ok(65535)
  assert u16::parse("65536") == Err(Nil)
  assert u16::parse_base("ffff", 16) == Ok(65535)
  assert u16::show(u16::max_value) == "65535"
  assert "{small}" == "7"
}
```

### Comparison

```cheby
test "comparing u16 values" {
  assert u16::compare(1, 2) == Less
  assert u16::compare(3, 3) == Equal
  assert u16::min(100, 7) == 7
  assert u16::max(100, 7) == 100
}
```

### Arithmetic

```cheby
test "u16 operators as functions" {
  assert u16::add(200, 55) == 255
  assert u16::sub(7, 2) == 5
  assert u16::mul(15, 17) == 255
  assert u16::div(7, 2) == 3
  assert u16::rem(7, 2) == 1
  assert u16::neg(0) == 0
  assert u16::abs(7) == 7
}
```

### Checked arithmetic

```cheby
test "u16 checked arithmetic reports overflow" {
  assert u16::checked_add(200, 55) == Ok(255)
  assert u16::checked_add(u16::max_value, 1) == Err(Nil)
  assert u16::checked_sub(0, 1) == Err(Nil)
  assert u16::checked_mul(u16::max_value, 2) == Err(Nil)
  assert u16::checked_div(7, 0) == Err(Nil)
  assert u16::checked_rem(7, 2) == Ok(1)
  assert u16::checked_neg(0) == Ok(0)
  assert u16::checked_neg(1) == Err(Nil)
}
```

### Wrapping arithmetic

```cheby
test "u16 wrapping arithmetic wraps around" {
  assert u16::wrapping_add(u16::max_value, 1) == 0
  assert u16::wrapping_sub(0, 1) == u16::max_value
  assert u16::wrapping_mul(u16::max_value, 2) == u16::max_value - 1
  assert u16::wrapping_neg(1) == u16::max_value
}
```
