# `std::u8`

The module of the built-in `U8` type, an unsigned 8-bit integer (§3.3.3, D-105). `U8` is in the prelude (D-112), and this module is where the type is declared (§8.2):

```cheby
pub type U8
```

A `U8` holds the integers from 0 to 255. Arithmetic is checked at that width, so a result outside the range panics (D-025). On JS it is a number checked to this range (§12.3.3), so `U8` behaves the same on every target (D-106).

The functions of this module are the integer families of [Numeric modules](README.md#numeric-modules), which define them for every integer type. The table below lists each function with its signature and family, and the examples show one family each (D-350). `compare`, `show` and the arithmetic functions make `U8` satisfy `Compare`, `Show`, `Add`, `Sub`, `Mul`, `Div` and `Neg` (§8.7, §8.8).

There is no conversion from `Float` or `F32`. A float becomes a `U8` through a rounding function such as `float::truncate` and then `u8::from_int` (D-359). The conversions from `U8` to other types are in their modules, such as `int::from_u8` and `float::from_u8`. The bitwise operators are built in (§5.4.6), so there are no functions for them, and the functions `std::int` has outside the families are not repeated here (D-389, D-391).

`U8` has no negative values, so `neg` and `checked_neg` succeed only for 0, `abs` returns its argument, and `wrapping_neg(n)` is 2⁸ − n for every other `n`.

Every function costs O(1), except `parse` and `parse_base`, which cost O(n) in the length of the text. The costs are informative.

## Examples

### Constants

```cheby
test "the u8 range" {
  assert u8::min_value == 0
  assert u8::max_value == 255
}
```

### Conversions

```cheby
test "conversions to u8" {
  assert u8::from_u32(200) == Ok(200)
  assert u8::from_u32(0x1234 & 0xFF) == Ok(0x34)
  assert u8::from_int(256) == Err(Nil)
  assert u8::from_i8(-1) == Err(Nil)
}
```

### Parsing and text

```cheby
test "u8 parses and shows decimal digits" {
  let small: U8 = 7
  assert u8::parse("255") == Ok(255)
  assert u8::parse("256") == Err(Nil)
  assert u8::parse("-1") == Err(Nil)
  assert u8::parse_base("ff", 16) == Ok(255)
  assert u8::show(255) == "255"
  assert "{small}" == "7"
}
```

### Comparison

```cheby
test "comparing u8 values" {
  assert u8::compare(1, 2) == Less
  assert u8::compare(3, 3) == Equal
  assert u8::min(100, 7) == 7
  assert u8::max(100, 7) == 100
}
```

### Arithmetic

```cheby
test "u8 operators as functions" {
  assert u8::add(200, 55) == 255
  assert u8::sub(7, 2) == 5
  assert u8::mul(15, 17) == 255
  assert u8::div(7, 2) == 3
  assert u8::rem(7, 2) == 1
  assert u8::neg(0) == 0
  assert u8::abs(7) == 7
}
```

### Checked arithmetic

```cheby
test "u8 checked arithmetic reports overflow" {
  assert u8::checked_add(200, 55) == Ok(255)
  assert u8::checked_add(u8::max_value, 1) == Err(Nil)
  assert u8::checked_sub(0, 1) == Err(Nil)
  assert u8::checked_mul(u8::max_value, 2) == Err(Nil)
  assert u8::checked_div(7, 0) == Err(Nil)
  assert u8::checked_rem(7, 2) == Ok(1)
  assert u8::checked_neg(0) == Ok(0)
  assert u8::checked_neg(1) == Err(Nil)
}
```

### Wrapping arithmetic

```cheby
test "u8 wrapping arithmetic wraps around" {
  assert u8::wrapping_add(u8::max_value, 1) == 0
  assert u8::wrapping_sub(0, 1) == u8::max_value
  assert u8::wrapping_mul(u8::max_value, 2) == u8::max_value - 1
  assert u8::wrapping_neg(1) == u8::max_value
}
```
